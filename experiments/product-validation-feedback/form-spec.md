# OKS 产品验证反馈表单规范

表名：`OKS 产品验证反馈`

推广权限：飞书 UI 设置为“持链接可填写”。不收集联系方式，也不增加隐藏字段或 Agent 专属字段。

| # | 字段 | 类型 | 必填 | 选项 / 说明 |
| --- | --- | --- | --- | --- |
| 1 | 本次希望 OKS 完成什么 | 多行文本 | 是 | 用户用自己的话描述目标。 |
| 2 | Agent 运行信息 | 多行文本 | 否 | 可粘贴简短事实；不得包含来源原文、URL、原始查询或凭据。 |
| 3 | 最终结果是否符合预期 | 单选 | 是 | 符合预期 / 部分符合预期 / 不符合预期 |
| 4 | Candidate Review 是否可判断 | 单选 | 是 | 能判断 / 有点拿不准 / 不能判断 / 本轮没有 Review |
| 5 | Guided Decision 体验 | 单选 | 是 | 有帮助 / 一般 / 有点打扰 / 更困惑 / 本轮没遇到 |
| 6 | Recall 结果 | 单选 | 是 | 找到且有帮助 / 找到但帮助不大 / 部分找到 / 没找到 / 本轮未使用 |
| 7 | 其他反馈 | 多行文本 | 否 | 最不舒服、最困惑或最希望改进的地方。 |

不要将现有 27 字段 Feishu 采集/审核控制表改造成这张表，也不要让两张表互相读写。
