# 参考

查阅性材料 —— 日常使用不需要读，改协议、写 Provider、做部署或评测时才需要。

**契约与字段**

- **Frontmatter Schema** — wiki 页面的每个字段是什么、谁写它
- **Raw 多模态协议入口** — Raw Bundle 与证据对象的机器事实源在哪
- **OKF 兼容性** — 与 Open Knowledge Format 的关系与差异

**度量与追溯**

- **Recall Evaluation** — 用标注数据集量化召回质量（Recall@k / MRR / nDCG）
- **Execution Traces** — 追加式执行轨迹：记录什么，以及为什么它是 provenance 而非知识

**部署与安全**

- **一键部署提示词** — 让 Agent 自行完成安装与项目接管
- **远程处理与凭证治理** — 什么情况下内容才允许发给第三方 Provider

**立场说明**

- **分区与 Spaces 立场** — 为什么不做多知识库分区
