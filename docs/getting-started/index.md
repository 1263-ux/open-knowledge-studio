# 开始使用

> 从零开始，快速上手 OKS。

这个章节包含从安装到第一次成功召回的完整路径。

---

## 推荐路径

### 新手路径（推荐）

1. **[安装](installation.md)** — 2 分钟安装 OKS
2. **[5 分钟见效](quick-wins.md)** — 立即体验核心价值
3. **[第一个知识闭环](first-loop.md)** — 用真实资料跑通流程

**总时间**：~20 分钟

### 快速路径

已经了解基本概念，直接开始：

1. **[安装](installation.md)** — 确保已安装
2. **[第一个知识闭环](first-loop.md)** — 完整流程
3. **[最佳实践](../best-practices.md)** — 深入学习

---

## 3 个关键文档

### 1. 安装

**文档**：[安装](installation.md)

**内容**：
- 用 pipx 安装 OKS
- 初始化知识库
- 验证安装

**时间**：2-5 分钟

---

### 2. 5 分钟见效

**文档**：[5 分钟见效](quick-wins.md)

**内容**：
- 选一份真实资料
- 对 Agent 说一句话
- 审核并晋升
- 测试召回

**时间**：5-8 分钟

**适合**：想快速体验 OKS 的价值

---

### 3. 第一个知识闭环

**文档**：[第一个知识闭环](first-loop.md)

**内容**：
- 完整流程：收录 → 审核 → 召回
- 成功信号和故障排除
- 真实案例参考

**时间**：10-15 分钟

**适合**：想系统学习完整流程
