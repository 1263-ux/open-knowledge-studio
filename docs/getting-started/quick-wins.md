# 快速见效指南

> 5 分钟体验 OKS 的核心价值：收录 → 审核 → 召回。

这个指南帮助你快速验证 OKS 能为你做什么，不需要深入学习所有概念。

---

## 你需要的时间

- **准备**：已安装 OKS（2 分钟）
- **操作**：跟随 3 个步骤（5 分钟）
- **验证**：看到知识被召回（1 分钟）

**总计**：~8 分钟

---

## 第 1 步：选一份真实资料

> ⚠️ **不要用测试数据**：选一份你真正看过、真正想记住的资料。

**推荐资料类型**：
- ✅ 最近看过的技术文章
- ✅ 工作中的决策文档
- ✅ 有用的技术视频（配字幕）

**不推荐**：
- ❌ 随手找的测试 PDF
- ❌ 没看过的长文章
- ❌ 娱乐内容

---

## 第 2 步：对 Agent 说一句话

在知识库目录中，对兼容 Agent（如 Claude Code）说：

```
收录这篇文章/这个视频/这个 PDF。
保留来源证据，生成 Candidate 后停下来让我审核。
```

**Agent 会做什么**：
1. 判断资料类型（文章/视频/PDF）
2. 选择合适的 Provider
3. 提取内容和元数据
4. 生成 Draft Candidate

**成功信号**：
- Agent 报告 Raw Bundle 位置
- Agent 报告 Candidate 位置
- 没有报错

**时间**：1-3 分钟（取决于资料大小）

---

## 第 3 步：审核并晋升

### 查看 Draft

```bash
oks drafts list
```

你会看到刚生成的 Draft：

```
drafts/your-article-title.md  [concept]  2026-08-20
```

### 阅读 Draft 内容

```bash
cat drafts/your-article-title.md
```

或用编辑器打开：

```bash
code drafts/your-article-title.md
```

### 快速检查

只需检查 3 点：

1. ✅ **标题准确吗？**
2. ✅ **核心内容完整吗？**
3. ✅ **有没有明显错误？**

如果通过，晋升：

```bash
oks drafts promote your-article-title
```

**成功信号**：

```
✅ Promoted to wiki/your-article-title.md
```

**时间**：1-2 分钟

---

## 第 4 步：测试召回

用你未来真的会问的问题召回：

```bash
oks recall "你会问的真实问题"
```

**示例**：

如果你收录的是 Kimi K3 评测视频：

```bash
oks recall "Kimi K3 成本怎么样"
```

**成功信号**：

```
[1] Kimi K3 实测 — 1天烧完1个月算力，普通人慎买
    score=0.84, relevance=1.92
    
    成本：20元/次、300+元/十几小时...
```

**时间**：< 1 分钟

---

## 验证完成

你已经完成了 OKS 的核心闭环：

```
✅ 收录：资料 → Raw Bundle → Draft
✅ 审核：Draft → 人工检查 → Wiki
✅ 召回：自然问题 → 找到知识
```

---

## 立即体验价值

现在对 Agent 问一个相关问题：

```
"我要设计 XXX 系统，[你的主题] 适合吗？"
```

**Agent 会**：
1. 自动召回你刚晋升的 Wiki
2. 基于你的知识回答问题
3. 标注知识来源

**对比效果**：

| | 没有 OKS | 有 OKS |
|---|---------|--------|
| **知识来源** | 通用训练数据 | 你刚看过的资料 |
| **数据准确** | 模糊 | 具体数字 |
| **可追溯** | 无法验证 | 关联原始资料 |

## 为什么这样设计

**为什么要人工审核？**
- AI 提取可能有误差
- 错误知识比没知识更危险
- 人工审核是质量保障的唯一途径

**为什么不能跳过 Draft？**
- Draft 是 Agent 的提案，不是最终知识
- 只有经过审核的内容才能进入 Wiki
- 这是 OKS 的核心设计原则

**为什么要保留 Raw？**
- Raw 是可追溯的来源
- 未来可以重新提取
- 审核时可以对照原文

---

**核心原则**：OKS 不是自动化笔记软件，是**人机协作的知识工作台**。Agent 提取，人审核，共同构建可信赖的知识库。

5 分钟体验，终身受益。
