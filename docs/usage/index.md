# 日常使用

日常使用时，你只需要表达意图和做决定。收集、整理、保存与召回由 Agent 调用 OKS 完成。

| 你要做什么 | 页面 |
|---|---|
| 把文章、文件、视频或对话变成可追溯材料 | [收集来源](ingest.html) |
| 决定 Candidate 是否值得成为长期知识 | [审核候选](review.html) |
| 让 Agent 在任务中使用已审核知识 | [召回与注入](recall.html) |
| 告诉系统当前是谁、在做什么、什么更重要 | [Goal 与 Profile](profiles.html) |

遇到问题时，让 Agent 先说明失败发生在哪一层，不要一次调整所有配置。
