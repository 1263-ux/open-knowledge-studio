# 真实案例

这里展示 OKS 在真实问题中怎样工作，不是另一组产品功能。每个案例都交代问题、人机边界、已有证据、实际结果和仍未验证的部分。

| 案例 | 要解决的问题 | 当前状态 |
|---|---|---|
| [托管你的研究](study.html) | 如何把一次 Kimi 研究变成可继续修正的研究循环 | 两个来源已保存，知识提议仍待人审 |
| [托管你的简历](resume.html) | 如何把一份履历和目标岗位要求变成可核对的候选简历 | 已完成脱敏岗位对照；投递与面试结果未验证 |
| [托管你的项目维护](maintainer.html) | 如何让一次修复成为下一位 Agent 可复用的经验 | 已完成一次文档与实现闭环 |
| [托管你的移动审核](feishu.html) | 人不在电脑前时，如何继续提供审核反馈 | 参考集成，不属于 OKS 核心 |

案例中的“部分完成”是事实边界。没有证据、人工审核或可复现结果的步骤，不会被写成已经完成。
