# PR 说明：合并 oks-connector 进入 open-knowledge-studio

> **历史快照** — 本文记录特定时间点的过程与决策，不代表当前口径。
> 现行设计以 [`CONSTITUTION.md`](../../CONSTITUTION.md) 为准；归档说明见 [归档索引](README.md)。

## 概述

将 `oks-connector`（独立多模态提取 CLI）合并入 `open-knowledge-studio` 单仓库。并新增组件化能力安装、飞书集成、Agent 摘要层、中英双语支持。

- 分支：`codex/upstream-v0.2.3-integration`
- 基于：`open-agent-power/open-knowledge-studio` main (v0.2.4)
- 变更：100 files, +14,214 / -570 lines

## 核心变更

### 架构：两仓库 → 单仓库

```
原来：
  open-knowledge-studio (CLI, 知识管理)
  oks-connector (提取引擎, 独立 pip 包)
  安装: pipx install studio + pipx inject connector + pipx inject connector[watch]

现在：
  open-knowledge-studio (全部)
  安装: pipx install ... --subdirectory=cli[watch]
```

`oks-connector` 入口点保留（`oks-connector` 二进制仍可用），代码搬入 `scripts/` 目录。

### 提取器模块化

原来 `raw_bundle_adapter.py` 为 3701 行单文件。现拆为：

```
scripts/
├── raw_bundle_adapter.py (777行)  主控制器
├── constants.py                   全局常量
├── _shared.py                     公共工具+元数据
├── route.py                       来源→提取器路由
├── capability_check.py            能力检测
├── digest.py                      Agent摘要+索引
├── network.py                     安全HTTP探测
├── validator.py                   Bundle校验
├── i18n.py                        中英双语
└── extractors/
    ├── watch.py (1044行)          视频/音频
    ├── markitdown.py (481行)      Office/HTML
    ├── mineru.py (148行)          PDF
    └── image.py (189行)           图片OCR
```

无循环依赖：提取器只依赖 `_shared` + `constants`。

### 新增功能

- **组件化能力安装**：`oks capability install watch|document|pdf|formula --yes`，`sys.executable -m pip install` 直接装进当前 venv
- **提取档位**：quick（平台字幕，2秒）和 forensic（字幕锚点帧 + Whisper + OCR）
- **飞书集成**：`oks feishu setup` 自动建Base/表/表单，submit→run-once 全链路
- **Agent 摘要**：每次 ingest 自动生成 `digest.md` + 更新 `raw/index.json`
- **Agent 技能**：`.claude/skills/` 下 9 个 skill 文件
- **错误诊断**：中文面板 + stderr 完整传播 + 路由诊断含 25 种支持格式
- **中英双语**：`OKS_LANG=zh|en` 自动切换
- **Root 检测**：当前目录有 `wiki/` 时优先使用，不用手动设 OKS_ROOT

## 可能的合并冲突

1. **`cli/pyproject.toml`**：新增了 `[project.optional-dependencies]` 的 watch/document/pdf/formula extras。如果上游也改了 extras，需要手工合并
2. **`cli/knowledge_studio/cli.py`**：改动较大（~400 行新增/修改），主要集中在 ingest 命令和能力系统。冲突可能出现在上游新增命令的地方
3. **`CONSTITUTION.md`**：P5 有较大重写。如果上游也改了 P5，需要注意
4. **`cli/knowledge_studio/config.py`**：`get_kb_root()` 逻辑变化很小（加了 cwd 检测），冲突概率低
5. **`settings/handlers.json`**：更新了 connector 路径引用

## 合并后上游需要注意的

1. **`console_scripts` 新增 `oks-connector`**：`pyproject.toml` 多了 `oks-connector = "raw_bundle_adapter:main"` 入口点
2. **`scripts/` 目录激增**：从原来的～5 个辅助脚本变成 15+ 个文件
3. **Python 版本要求提到 3.12**：原 `>=3.10` → `>=3.12`
4. **测试从 39 项增加到至少 48 项**：新增 `cli/tests/test_optional_extensions.py`
5. **`pipx inject oks-connector` 不再需要**：README 和文档需要同步更新
