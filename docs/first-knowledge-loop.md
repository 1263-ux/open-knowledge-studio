# 第一次学习循环

第一次不要导入全部资料。只教 Agent 学会一条真实、短小、以后还会用到的判断。

## 1. 给出材料和边界

把一段文字、一个文件或一条链接交给 Agent，并说明：

> 请把这份材料纳入 OKS。保留来源，区分原文主张和你的推断；先提出待审核知识，不要直接写成长期知识。完成后告诉我保存了什么、缺少什么、需要我决定什么。

成功时，Agent 应报告来源是否取得、证据是否完整，以及形成了哪些待审核提议。失败和跳过也必须按原状态报告。

## 2. 审核 Agent 的提议

对 Agent 说：

> 请逐条展示待审核提议，同时给出对应来源、证据范围、与已有知识的关系，以及仍未核验的内容。

你需要判断：

- 这句话是否忠实表达来源；
- 它是事实、来源观点，还是 Agent 推断；
- 它是否补充、取代或挑战已有知识；
- 它是否值得在未来任务中主动出现。

你可以接受、修改、拒绝，或者暂不决定。只有你明确接受的部分，Agent 才能保存为长期知识。

## 3. 换一个问题验证

不要让 Agent 复述刚才的内容。开启一个新任务，提出一个确实需要这条知识的问题，并要求 Agent 说明它使用了哪条已审核知识。

成功不是“答对一句话”，而是 Agent 能说明：

- 使用了哪条经过审核的知识；
- 这条知识来自哪里；
- 它如何影响了当前答案；
- 当前问题是否超出已有证据。

## 验收清单

- [ ] 原始来源可以定位。
- [ ] Agent 的提议没有绕过人工审核。
- [ ] 接受、修改或拒绝都有记录。
- [ ] 新任务使用的是已审核知识，不是把原始材料当作结论。
- [ ] 证据不足时，Agent 会说明缺口。
