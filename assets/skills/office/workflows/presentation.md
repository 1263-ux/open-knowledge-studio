# PowerPoint workflow

Use the host `presentations` workflow for production decks: inspect the
template first, build the argument before layout, use native objects, and
render every slide. Keep one decision per slide and make the source ledger or
source notes legible.

Use `ppt-master` only as an optional high-quality Adapter after its local probe
passes. Its output still requires the same evidence package and complete
visual inspection. If the presentation skill is unavailable, report
`environment_limited`; do not substitute a local serialization-only deck.
