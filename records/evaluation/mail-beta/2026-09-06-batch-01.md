## What this batch proves

- Claude → Codex、Codex → Claude、Human → Agent 三条路都已有真实 CLI 证据。
- OKS Core 的 durable Thread、per-Session receipt、显式 ack、same-Thread reply 和跨
  Session archive 语义在这些场景中可观察、可复核。
- 第一轮的核心指标是正向的：没有发生背景重复询问，也没有重复最终决策。
- 当前最大缺口在 Claude headless 的宿主权限与 Session identity 对齐，不在 canonical
  message 或 receipt 存储层。
