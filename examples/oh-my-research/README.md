# 托管你的学习

*把看过的文章、视频、课程，变成一套随时能“想起来”的知识。*

## 为什么需要它

你有没有这种感觉：收藏了一堆好文章，刷了很多视频，当时觉得“学到了”，过几周再问自己，却说不出来到底学了什么？

不是你不努力，而是学过的东西散落在收藏夹、聊天记录和硬盘里，没有变成“你的知识”。

OKS 帮你做三件事：

## 第一步：收集

看到值得学的东西——文章、视频、课程、聊天里的一句话——先放进 OKS 的“资料箱”。

不用整理，不用分类，原样放进去就行。这一步只做一件事：**别让它丢**。

## 第二步：沉淀

隔一段时间，从资料箱里挑一篇，用自己的话写下“我学到了什么”。

不用写长文，三五句话就够。比如读完一篇讲 AI 记忆的文章，写下：

> AI 记忆分三层：短期工作记忆、长期知识、可被检索的外部知识库。

这一步不是给别人看的，是做给未来的自己看的：**把别人的内容，变成自己的话。**

## 第三步：想起来

以后写代码、写方案、或者单纯想不起来了，直接问 OKS：

> “AI Agent 的记忆体系是怎么设计的？”

OKS 会把相关的沉淀翻出来给你，不用再去翻收藏夹。

## 一个真实的例子

以《深入理解 AI Agent》第 3 章为例：

1. **收集**：把第 3 章放进资料箱。
2. **沉淀**：写下要点——AI Agent 记忆分三层、四种存储格式、Mem0 v2→v3 的演进。
3. **想起来**：某天写方案时问“AI Agent 记忆体系怎么设计”，OKS 自动把要点找出来：

> **AI Agent 记忆与知识库体系**（来源：《深入理解 AI Agent》第 3 章）
> 三层次评估 / 四种存储格式 / 认知三类 / RAG 技术栈 / 结构化索引 / 双层架构

知识会在你需要的时候自己浮现，不用刻意去翻。

## 怎么开始

1. 选一个你正在学的东西：一本书的一章、一门课的一节、一篇想弄懂的文章。
2. 把它放进 OKS 的资料箱。
3. 学完后，用自己的话写 3–5 条要点。
4. 下次用到时，问 OKS，看看能不能想起来。

先跑通一次，再决定要不要整理更多。
