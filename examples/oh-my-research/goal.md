# 示例 Goal：学透一本书的核心章节

> 这是可复制的示例，不是已激活的个人目标。复制到你的 OKS 实例后，把书名、章节
> 和你想学的内容改成自己的，再把 `status` 改为 `active`。

## 我想学会什么

读完这本书，能用自己的话讲清楚“AI Agent 的记忆和知识库是怎么设计的”。

## 我打算怎么学

- [ ] 把要学的章节放进资料箱（raw）。
- [ ] 读完后，用自己的话写 3–5 条要点（wiki）。
- [ ] 过几天问自己几个问题，看能不能回想起来。
- [ ] 想不起来或答错的，回头再看一遍，补上遗漏。

## 边界

- 只学对当前工作有用的部分，不追求全书搬运。
- 没看懂的地方先记录问题，不假装理解。
- 学习产物先放草稿，确认有效再沉淀成记忆。
